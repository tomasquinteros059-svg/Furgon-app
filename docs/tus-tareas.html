1. Supabase Gratis

La base de datos y el servidor de la app. ≈ 10 min.

  1. Crea tu cuenta (puedes entrar con GitHub).
    Crear cuenta
  2. Crea el proyecto: nombre furgon-app, región South America (São Paulo), plan Free. Genera la contraseña de la base de datos y guárdala en tu gestor.
    Nuevo proyecto
  3. Anota el Project ref: el código que aparece en la dirección del proyecto, supabase.com/dashboard/project/abcdefghijklmnop. No es secreto.
  4. Crea un Access token llamado furgon-despliegue y cópialo a tu gestor (se muestra una sola vez). Es secreto.
    Access tokens

2. Google Maps Crédito gratis mensual · pide tarjeta

Tiempo de llegada con tráfico, ruta por calles y ruta recomendada. ≈ 15 min.

  1. Crea el proyecto furgon-app.
    Crear proyecto
  2. Activa la facturación del proyecto (tarjeta).
    Facturación
  3. Crea un presupuesto con alerta, por ejemplo USD 20, para que nunca haya sorpresas.
    Presupuestos y alertas
  4. Habilita Routes API (con el proyecto furgon-app seleccionado arriba).
    Routes API
  5. Crea una Clave de API llamada furgon-servidor. Restricciones de aplicación: Ninguna. Restricciones de API: Restringir clave → Routes API. Cópiala a tu gestor. Es secreta.
    Credenciales

Aquí dejas las claves para que yo pueda desplegar. ≈ 5 min.

  1. En esta sesión de Claude Code, abre el menú del entorno en la barra del título y toca Edit.
    Ayuda del entorno
  2. Network access → Allowed domains (deja marcado «Allow package managers»), agrega:
    api.supabase.comdesplegar
    *.supabase.cotu proyecto
    routes.googleapis.comprobar la clave de Google
    *.expo.devcompilar las apps (bloque 5)
  3. Variables de entorno, agrega:
    SUPABASE_PROJECT_REFel Project ref (bloque 1)
    SUPABASE_ACCESS_TOKENel Access token (bloque 1)
    GOOGLE_MAPS_API_KEYla clave furgon-servidor (bloque 2)
  4. Abre una sesión nueva y escribe: «despliega Supabase».
    Yo: subo la base de datos, las funciones y las tareas automáticas, y pruebo Google.
  5. Crea tu usuario: Add user → Create new user, con tu correo y una contraseña, y marca Auto Confirm User. Luego dime tu correo y si eres administrador o tía.
    Usuarios de Supabase
    Yo: creo la empresa y te doy el rol.

4. Llamadas telefónicas: Twilio Pago por minuto

Solo para cuando el teléfono de la familia no tiene internet. Sin esto igual funciona la alarma y la llamada gratis por la app. ≈ 20 min.

  1. Crea tu cuenta.
    Crear cuenta Twilio
  2. Para probar con la cuenta de prueba: verifica tu propio teléfono (solo llama a números verificados).
    Números verificados
  3. Compra un número con capacidad Voice y anótalo en formato +56….
    Comprar número
  4. Copia el Account SID y el Auth Token (secreto) desde «Account Info».
    Consola Twilio
  5. En las variables del entorno (bloque 3) agrega:
    TWILIO_ACCOUNT_SIDAccount SID
    TWILIO_AUTH_TOKENAuth Token
    TWILIO_NUMERO_ORIGENel número, p. ej. +56221234567
    LLAMADAS_HABILITADAStrue
    Abre una sesión nueva y escribe: «activa las llamadas».

5. Apps de Android e iPhone

Para instalar las apps de prueba en teléfonos reales. ≈ 1 h.

  1. Crea tu cuenta de Expo Gratis
    Crear cuenta Expo
  2. Crea un Access token de Expo y guárdalo en las variables del entorno como EXPO_TOKEN. Es secreto.
    Tokens de Expo
  3. En Google Cloud habilita Maps SDK for Android y Maps SDK for iOS.
    Maps SDK Android Maps SDK iOS
  4. Crea dos claves nuevas: furgon-android (restringida a apps Android, paquete cl.furgonapp.movil; la huella SHA-1 te la doy yo) y furgon-ios (apps iOS, bundle cl.furgonapp.movil). Guárdalas como GOOGLE_MAPS_ANDROID_API_KEY y GOOGLE_MAPS_IOS_API_KEY en el entorno.
    Credenciales
  5. Notificaciones de Android: crea un proyecto en Firebase (puedes elegir el mismo furgon-app de Google Cloud) y agrega una app Android con paquete cl.furgonapp.movil. Luego Configuración del proyecto → Cuentas de servicio → Generar nueva clave privada y súbela en Expo (Credentials → Android → FCM V1). El archivo es secreto: no lo mandes por chat.
    Firebase
  6. Escribe: «compila la app de Android».
    Yo: genero el APK y te dejo el enlace/QR para instalarlo.
  7. Para iPhone: inscríbete en Apple Developer Program USD 99 al año (la aprobación puede tardar 1–2 días).
    Apple Developer
  8. Prueba en teléfonos reales: un recorrido con la app en segundo plano, la alarma con el teléfono bloqueado y la llamada. En Xiaomi, Huawei o Samsung, quita la app de la optimización de batería.

6. Panel web en internet: Vercel Gratis

Para entrar al panel de administración desde cualquier computador. ≈ 15 min.

  1. Crea tu cuenta con GitHub.
    Crear cuenta Vercel
  2. Importa el repositorio furgon-app. Root Directory: apps/admin. Variables: VITE_SUPABASE_URL y VITE_SUPABASE_ANON_KEY (te las doy yo después del despliegue; son públicas).
    Nuevo proyecto
  3. Pon la dirección que te da Vercel como Site URL en Supabase y dímela.
    URL Configuration
