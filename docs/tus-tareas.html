A. Expo Gratis

Para compilar las apps. Tu correo de GitHub ya tiene una cuenta de Expo.

  1. Restablece la contraseña de Expo con el mismo correo de tu GitHub y abre el enlace que te llega.
    Restablecer contraseña
  2. Entra a Expo con ese correo y la contraseña nueva.
    Entrar a Expo
  3. Crea un token: botón Create token, nombre furgon-claude. Cópialo a tu gestor. Secreto.
    Tokens de Expo

B. Supabase y Google Maps

Si ya los creaste, solo revisa que tengas a mano estos tres valores.

  1. Project ref de Supabase: abre tu proyecto furgon-app y copia el código de la dirección: supabase.com/dashboard/project/este-codigo. No es secreto.
    Mis proyectos
  2. Access token de Supabase: Generate new token, nombre furgon-despliegue. Secreto.
    Access tokens
  3. Clave de Google furgon-servidor con Routes API habilitada (proyecto furgon-app seleccionado arriba). Secreta.
    Habilitar Routes API Credenciales
  4. Habilita los mapas para las apps: Maps SDK for Android y Maps SDK for iOS (botón Habilitar en cada una). Las claves de las apps las creamos después, en el paso 14, con la huella que te paso.
    Maps SDK Android Maps SDK iOS

E. Durante esa sesión nueva

  1. Crea tu usuario en Supabase: Add user → Create new user, tu correo y una contraseña, y marca Auto Confirm User. Luego dime en el chat tu correo y si eres administrador o tía.
    Usuarios de SupabaseYo: creo tu empresa y te doy el rol.
  2. Claves de mapas para las apps, con la huella SHA-1 que te paso: Crear credenciales → Clave de API, dos veces.
    furgon-androidApps de Android → paquete cl.furgonapp.movil + la huella SHA-1. API: Maps SDK for Android.
    furgon-iosApps de iOS → bundle cl.furgonapp.movil. API: Maps SDK for iOS.
    Agrégalas al entorno como GOOGLE_MAPS_ANDROID_API_KEY y GOOGLE_MAPS_IOS_API_KEY. Secretas.
    Credenciales
  3. Firebase, para las notificaciones de Android: Crear proyecto → elige el proyecto existente furgon-app de Google Cloud. Luego Agregar app → Android, paquete cl.furgonapp.movil.
    Firebase
  4. Clave de Firebase a Expo: en Firebase, Configuración del proyecto → Cuentas de servicio → Generar nueva clave privada (descarga un archivo). En Expo, tu proyecto furgon-escolar → Credentials → Android → FCM V1 → Upload y sube ese archivo. El archivo es secreto: no lo mandes por chat.
    Cuentas de servicio Mis proyectos en Expo
  5. Instala el APK en tu Android con el enlace que te paso y prueba: inicia un recorrido con la cuenta de la tía y mira el aviso con la de la familia (en otro teléfono si tienes).

G. Llamadas telefónicas: Twilio Pago por minuto · opcional al principio

  1. Crea la cuenta y verifica tu teléfono.
    Crear cuenta Números verificados
  2. Compra un número con voz (casilla Voice).
    Comprar número
  3. Agrega al entorno TWILIO_ACCOUNT_SID, TWILIO_AUTH_TOKEN (secreto), TWILIO_NUMERO_ORIGEN (el número, p. ej. +56221234567) y LLAMADAS_HABILITADAS=true. Los dos primeros están en «Account Info».
    Consola Twilio
